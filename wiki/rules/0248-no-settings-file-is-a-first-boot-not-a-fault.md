# Rule 0248 — No settings file is a first boot, not a fault

**At the glass: a cabinet with nothing configured plays.** Every value takes its default, start-up
says the file was not found, and one sound set beside it is enough ([0248](../../raw/rules/0248-no-settings-file-is-a-first-boot-not-a-fault.md)). Pages:
[the cabinet](../bodies/cabinet.md).
