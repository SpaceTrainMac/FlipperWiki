FLYER02 is the only source that names the mechanisms, labelling them bilingually:

| Flyer (EN) | Flyer (ES) | Position |
|---|---|---|
| Elevator Holes | Agujeros elevadores | Two holes, upper centre — lift the ball to the upper level |
| Elevator Ramp | Rampa ascendente | Right, ascending |
| Return Track | Carril de retorno | Right, returning |
| Return raised Tunnel | Túnel elevado | Left, returning |
