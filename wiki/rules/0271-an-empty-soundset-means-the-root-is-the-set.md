# Rule 0271 — An empty `soundSet` means the root itself is the set

**At the glass: `NONE SET` under `SOUND SET` is not an empty machine, it is a machine looking in
the wrong place** ([0271](../../raw/rules/0271-an-empty-soundset-means-the-root-is-the-set.md)). A cabinet with one set can keep that set where the machine looks and
name nothing ([0271](../../raw/rules/0271-an-empty-soundset-means-the-root-is-the-set.md)). Pages: [sound sets](../concepts/sound-sets.md).
