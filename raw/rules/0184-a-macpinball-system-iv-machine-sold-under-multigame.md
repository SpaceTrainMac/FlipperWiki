It is a **MacPinBall System IV** machine sold under MAC's *MULTIGAME* scheme: the cabinet is a
reusable chassis, and a new title means changing only playfield, backglass and game EPROM. That is
why the matrices in [hardware.md](../../../FlipperArchitecture/docs/hardware.md) look generic — they are the chassis' matrices, not
Space Train's, which is also why several switches and lamps have no role in this game.

| | |
|---|---|
| Title | SPACE TRAIN |
| Manufacturer | MAC S.A., Madrid |
| Year | 1987 |
| System | MacPinBall System IV, board `A-01717` |
| Players | 1–4 |
| Playfield | Two physical levels |
| Balls in play | Up to 3 simultaneously *(the flyer's figure; this cabinet has a two-ball store and caps multiball at two — [gameplay.md §9](../../../FlipperArchitecture/docs/gameplay.md#9-the-bunkers-and-multiball))* |
| Captive balls | 3 |
