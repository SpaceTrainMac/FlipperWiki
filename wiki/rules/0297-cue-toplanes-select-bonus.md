# Rule 0297 — `TOPLANES_SELECT_BONUS`

**At the glass: the lane change has a sound** ([0297](../../raw/rules/0297-cue-toplanes-select-bonus.md)), which is the only *selection* the top lanes
offer — and it needed no minimum interval, because a held button does not rotate anything twice
([0297](../../raw/rules/0297-cue-toplanes-select-bonus.md)). Pages: [what the machine says](../concepts/the-sounds.md), [the flipper buttons](../things/flipper-buttons.md).
