# Rule 0316 — Adding one later is cheap and adding one now is not free

**At the glass: the four silences are not permanent** — a cue costs an enum, a key in four
manifests and a file in each of four sets, and a set that lacks one is quiet rather than broken, so
one can be added whenever a rule earns it ([0316](../../raw/rules/0316-adding-a-cue-later-is-cheap.md)). Pages:
[what the machine says](../concepts/the-sounds.md).
