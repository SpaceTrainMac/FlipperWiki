# Rule 0146 — `BUTTON_START`

**Pays:** —. **Advances:** starts a game and adds players, **at player select and nowhere else**. A game in progress does not read it (§12). **Collects:** —. ([0146](../../raw/rules/0146-button_start.md))

It is explained on [start button](../things/start-button.md).
