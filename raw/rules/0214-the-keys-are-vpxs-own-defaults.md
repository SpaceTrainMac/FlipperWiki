**The keys are VPX's own defaults and this table changes none of them.**

| Key | |
|---|---|
| **Left Shift / Right Shift** | The flippers |
| **Enter** | The plunger. Hold to pull back, release to fire |
| **1** or **S** | Start. This is the machine's own start button, and the engine sees it. **Once a game is running it does nothing** — the paragraph below. `1` is VPX's own Start key and follows anything you rebind it to; `S` is the letter itself, and it is this table's |
| **Z / `/` / Space** | Nudge left, right, forward |
| **Esc** | Leave. **Use it rather than killing the player** — [§6](../../../FlipperVPX/docs/using-the-table.md#6--when-it-does-not-do-what-you-expect) |
