# Rule 0438 — Adding one later is cheap and adding one now is not free

**At the glass: the four silences are not permanent** — a cue costs an enum, a key in five
manifests, a score in four generators and a hand-found file for the one set that is collected
rather than generated, and a set that lacks one is quiet rather than broken, so one can be added
whenever a rule earns it ([0438](../../raw/rules/0438-a-cue-costs-five-manifests-and-four-generators.md)). It supersedes
[0316](../../raw/rules/0316-adding-a-cue-later-is-cheap.md), which counted four sets and three
generators.
