# Rule 0250 — A failed write is not renamed over a good file

**At the glass: `NOSAVE` is bad news that could have been much worse** — the write failed and the
file it would have replaced is untouched ([0250](../../raw/rules/0250-a-failed-write-is-not-renamed-over-a-good-file.md)). Until 2026-09-01 a card that filled mid-table
could put a truncated high score file over the only copy in existence; it cannot now ([0250](../../raw/rules/0250-a-failed-write-is-not-renamed-over-a-good-file.md)).
