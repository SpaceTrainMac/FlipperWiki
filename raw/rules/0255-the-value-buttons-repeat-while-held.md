| Button | Does |
|---|---|
| start | the next entry, wrapping round |
| right flipper | the current entry's next value |
| left flipper | its previous value |

The value buttons repeat while held. The top pair of score displays names the entry, the bottom pair
shows its value, and `MATCH` says `SETUP`.
