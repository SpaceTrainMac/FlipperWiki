# Rule 0251 — `volume` is system-wide

**At the glass: the volume belongs to the computer rather than to the game**, so anything else
running on it can change what the machine sounds like ([0251](../../raw/rules/0251-volume-is-system-wide.md)). All three bodies apply the same
stored level when they start ([0251](../../raw/rules/0251-volume-is-system-wide.md)). Pages: [the cabinet](../bodies/cabinet.md),
[the browser simulator](../bodies/simulator.md).
