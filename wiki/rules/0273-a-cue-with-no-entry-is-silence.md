# Rule 0273 — A cue with no entry is silence, and that is all it is

**At the glass: most things on this machine make no sound, on purpose** ([0273](../../raw/rules/0273-a-cue-with-no-entry-is-silence.md)). A set that maps
nothing to an event plays nothing there, and the cabinet runs normally ([0273](../../raw/rules/0273-a-cue-with-no-entry-is-silence.md)). Pages:
[sound sets](../concepts/sound-sets.md).
