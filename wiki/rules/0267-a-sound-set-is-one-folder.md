# Rule 0267 — A sound set is one folder

**At the glass: what this machine sounds like is a choice, not a build** — one folder is one voice,
the cabinet plays one at a time or all of them at once, and swapping is a setting rather than a
copy ([0267](../../raw/rules/0267-a-sound-set-is-one-folder.md)). Pages: [sound sets](../concepts/sound-sets.md).
