# Rule 0216 — A ball that drains in the first fifteen seconds is given back

**At the glass: it feels like the machine catching the ball.** Fifteen seconds from out-fire, once
a turn, and on this table the trough takes about 400 ms to put a ball back under the ejector before
it fires again ([0216](../../raw/rules/0216-a-ball-that-drains-in-the-first-fifteen-seconds-is-given-back.md)). `HOUSE_BALL` — lamp 228 — blinks the whole time ([0216](../../raw/rules/0216-a-ball-that-drains-in-the-first-fifteen-seconds-is-given-back.md)). Pages:
[drain protection](../concepts/drain-protection.md), [the HOUSE BALL lamp](../things/house-ball-lamp.md),
[the Visual Pinball table](../bodies/vpx.md).
