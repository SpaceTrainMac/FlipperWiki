# Rule 0244 — The operator's choices live in `settings.json`

**At the glass: nothing anybody can set changes what anything scores** ([0244](../../raw/rules/0244-the-operators-choices-live-in-settings-json.md)). Switch addresses,
the display timing and the 1987 values are facts and are compiled in; the twenty things an owner
picks — sound, volume, how long the credits run — are settings, and the line between them is
drawn on purpose ([0244](../../raw/rules/0244-the-operators-choices-live-in-settings-json.md)). Pages: [the cabinet](../bodies/cabinet.md).
