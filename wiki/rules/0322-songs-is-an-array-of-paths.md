# Rule 0322 — Not cues: `songs` is an array of paths

**At the glass: the jukebox's songs are a list rather than a set of named events** — addressed by
position, with no names to map, and the order is the order they play ([0322](../../raw/rules/0322-songs-is-an-array-of-paths.md)). Pages:
[what the machine says](../concepts/the-sounds.md).
