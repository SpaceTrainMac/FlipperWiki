# Rule 0252 — Hold both flippers for nine seconds while the cabinet is in attract mode

**At the glass: both flippers, nine seconds, in attract mode** ([0252](../../raw/rules/0252-hold-both-flippers-for-nine-seconds.md)). Every input this machine
has is a playfield switch or one of the three buttons, so the menu had to be reachable by a gesture
— and one that a cabinet does not perform by accident ([0252](../../raw/rules/0252-hold-both-flippers-for-nine-seconds.md)). Pages:
[the service menu](../moments/the-service-menu.md).
