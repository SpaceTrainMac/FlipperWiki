# Rule 0272 — An effect may name several files instead of one

**At the glass: this is why three hundred bumper hits in an evening do not sound like one bumper
three hundred times** ([0272](../../raw/rules/0272-an-effect-may-name-several-files.md)). An effect can name several files and `SFX MODE` decides how the
cabinet picks — a shuffled deck, or round in order — and `SOUND TEST` will name each variant as it
plays it ([0272](../../raw/rules/0272-an-effect-may-name-several-files.md)). Pages: [sound sets](../concepts/sound-sets.md).
