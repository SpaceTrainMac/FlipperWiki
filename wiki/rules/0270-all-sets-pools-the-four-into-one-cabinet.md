# Rule 0270 — `ALL SETS` pools the four into one cabinet

**At the glass: a bumper can answer in chiptune, then in an orchestra, then in a voice** — every
cue draws from every set that maps it and the playlists are concatenated ([0270](../../raw/rules/0270-all-sets-pools-the-four-into-one-cabinet.md)). The one thing to
expect from it is uneven volume: one mixer, no ducking, and four sets mastered separately ([0270](../../raw/rules/0270-all-sets-pools-the-four-into-one-cabinet.md)).
