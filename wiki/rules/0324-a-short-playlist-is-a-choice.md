# Rule 0324 — A short playlist is a choice and an empty one is legitimate

**At the glass: a machine with no jukebox music is not a machine missing something** ([0324](../../raw/rules/0324-a-short-playlist-is-a-choice.md)). The
only thing that counts against a playlist is an entry naming a file that is not on disk, and that
stops the cabinet like any other missing file ([0324](../../raw/rules/0324-a-short-playlist-is-a-choice.md)). Pages:
[what the machine says](../concepts/the-sounds.md), [sound sets](../concepts/sound-sets.md).
