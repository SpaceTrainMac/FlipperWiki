# Rule 0225 — `spacetrain-autoplay` plays a whole game with nobody at the keyboard

**At the glass: there is a way to watch this machine play itself, and it is not the table.** The
autoplayer talks to the engine through the switch matrix — no VPX, no window — presses start,
feeds the ejector, keeps every ball alive two seconds and enters initials at the end; a one-player
game takes about 29 seconds and a four-player one about 110 ([0225](../../raw/rules/0225-spacetrain-autoplay-plays-a-whole-game.md)). Pages:
[the Visual Pinball table](../bodies/vpx.md).
