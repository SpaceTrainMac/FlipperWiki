# Rule 0298 — `TOPLANES_SUPERBONUS`

awards — so the completion and the paying it turns on are the same thing happening ([0298](../../raw/rules/0298-cue-toplanes-superbonus.md)). Pages: [what the machine says](../concepts/the-sounds.md), [M-A-C](../concepts/m-a-c.md).
