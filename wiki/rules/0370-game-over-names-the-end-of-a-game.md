# Rule 0370 — `GAME OVER` names the end of a game

**At the glass: the lamp comes on when the last round ends, and everything after it — the draw,
the names, the table, the credits — is standing in a game that is already over** ([0370](../../raw/rules/0370-game-over-names-the-end-of-a-game.md)). Pages:
