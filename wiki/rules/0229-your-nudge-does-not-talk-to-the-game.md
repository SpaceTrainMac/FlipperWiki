# Rule 0229 — Your nudge does not talk to the game

**At the glass: nudge all you like, the game never hears it** — VPX handles the whole of it and
the engine sees an ordinary drain, exactly as the cabinet's own wiring handles a tilt without
telling the software ([0229](../../raw/rules/0229-your-nudge-does-not-talk-to-the-game.md)). So the `TILT` plate on this backbox is a drawing that can never
light ([0229](../../raw/rules/0229-your-nudge-does-not-talk-to-the-game.md)). Pages: [tilt](../concepts/tilt.md), [the sixteen indicator LEDs](../things/indicator-leds.md),
[the Visual Pinball table](../bodies/vpx.md).
