# Rule 0276 — 43 cues and a playlist

**At the glass: the machine has forty-three things it can say and one playlist it can play**, and
what each one is *for* is the same on every cabinet — only which file answers it changes with the
[sound set](../concepts/sound-sets.md) ([0276](../../raw/rules/0276-43-cues-and-a-playlist.md)). Pages:
[what the machine says](../concepts/the-sounds.md).
