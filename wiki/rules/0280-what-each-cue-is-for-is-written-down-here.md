# Rule 0280 — What each cue is *for* is written down here and nowhere else

**At the glass: the list of what the machine says is a promise rather than a report** — each cue's
event comes from its name and from the rules, the code was written to match it on 2026-09-08, and
every raise is pinned by a test ([0280](../../raw/rules/0280-what-each-cue-is-for-is-written-down-here.md)). A silence where this page says there is a sound is a
defect ([0280](../../raw/rules/0280-what-each-cue-is-for-is-written-down-here.md)). Pages: [what the machine says](../concepts/the-sounds.md).
