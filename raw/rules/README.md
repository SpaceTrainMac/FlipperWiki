# The rules

**One rule per file, the text verbatim with its provenance above it, and never edited.** The shape
is [CLAUDE.md](../../CLAUDE.md#a-rule-file). Numbered in the order added, four digits; the number is
an identity, not a ranking.

**When the machine changes, add a rule — do not change one.** The new file names the one it
supersedes in `supersedes:`, and the lint pass finds every page that still says the old thing.

A person may write one. `source: RooL, at the cabinet, 2026-09-14` is legal provenance, and it is
treated exactly like a paragraph cut from gameplay.md: raw, immutable, cited by number.
