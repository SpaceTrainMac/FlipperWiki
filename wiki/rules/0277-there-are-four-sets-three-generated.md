# Rule 0277 — There are four sets, and three of them are generated

**At the glass: whichever voice the machine is wearing, the list of things it can say is the same**
([0277](../../raw/rules/0277-there-are-four-sets-three-generated.md)). Three of the four sets are generated rather than collected, and all four map the same
cues to the same events ([0277](../../raw/rules/0277-there-are-four-sets-three-generated.md)). Pages: [what the machine says](../concepts/the-sounds.md),
[sound sets](../concepts/sound-sets.md).
