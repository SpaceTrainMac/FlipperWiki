# Observations

**What a person saw at a glass, dated, naming the body, never edited.** One file per evening:
`YYYYMMDD-<body>.md`, where the body is `cabinet`, `vpx` or `simulator`. Write what was seen in
the order it was seen, with no reference to any page — *the count took longer than I expected; the
knocker landed mid-transfer; the right EXTRA BALL was lit and the saucer did not collect it*. End
with one line saying whether anything disagreed with what you expected.

**It is ingested like a rule.** Where it disagrees with a rule, the rule's page gains a *Watched*
paragraph citing both; the wiki decides nothing, because it has no authority over the documents the
rules were cut from. A discrepancy is a finding next door with a citation at both ends.
