# Rule 0286 — `NEXT_PLAYER`

**At the glass: somebody else is up** ([0286](../../raw/rules/0286-cue-next-player.md)). It marks a turn passing to a *different* player,
so a one-player game never hears it and neither does the first turn of any game ([0286](../../raw/rules/0286-cue-next-player.md)). Pages: [what the machine says](../concepts/the-sounds.md), [the end of a turn](../moments/end-of-turn.md).
