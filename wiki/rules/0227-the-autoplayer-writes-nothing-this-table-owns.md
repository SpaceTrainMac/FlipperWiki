# Rule 0227 — It writes nothing this table owns

**At the glass: the autoplayer cannot get into your high score table.** Its score file and its
odometer are scratch paths under the system temp directory, and it clears its own before every run
([0227](../../raw/rules/0227-the-autoplayer-writes-nothing-this-table-owns.md)). Pages: [the Visual Pinball table](../bodies/vpx.md).
