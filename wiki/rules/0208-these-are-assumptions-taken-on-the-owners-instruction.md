# Rule 0208 — These are assumptions, taken 2026-08-26

**At the glass: nobody guessed quietly.** The four values the 1987 sources leave blank were settled
on the machine owner's instruction — *make assumptions, you decide, it can be changed later on* —
on a stated date, and each is written down with what it was decided from, so that overturning one
means beating an argument rather than noticing a gap ([0208](../../raw/rules/0208-these-are-assumptions-taken-on-the-owners-instruction.md)). Pages:
[decided where the sources are silent](../concepts/where-the-sources-are-silent.md).
