# Rule 0439 — Four events with no cue, across five sets

**At the glass: three of the four silences are deliberate and one is a gap the document admits to**
([0439](../../raw/rules/0439-four-events-with-no-cue-across-five-sets.md)). The transfer already sounds like something, the 5th hole-bonus hit speaks like the four
before it, and the thunderstrike is announced in light — but **a hole-bonus window expiring
uncollected costs 55 000 and says nothing**, and no cue was invented for it ([0439](../../raw/rules/0439-four-events-with-no-cue-across-five-sets.md)). **What keeps
that gap open is arithmetic**: a cue invented for it would cost five sets a file each, one of them
hand-found, and nobody has yet watched a window close ([0439](../../raw/rules/0439-four-events-with-no-cue-across-five-sets.md)). It supersedes
[0315](../../raw/rules/0315-four-events-with-no-cue.md), which counted four sets. Pages:
[what the machine says](../concepts/the-sounds.md), [the hole bonus](../concepts/the-hole-bonus.md).
