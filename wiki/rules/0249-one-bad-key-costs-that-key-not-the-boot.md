# Rule 0249 — One bad key costs that key, not the boot

**At the glass: the machine starts anyway.** A value it cannot read is warned about and replaced by
its default — a cabinet that would not start over a mistyped volume would be worse than a loud one
([0249](../../raw/rules/0249-one-bad-key-costs-that-key-not-the-boot.md)). Pages: [the cabinet](../bodies/cabinet.md).
