# Rule 0215 — The start button belongs to player select

**At the glass: after the first ball, do not press anything and do not wait for a prompt** — every
ball comes out on its own ([0215](../../raw/rules/0215-the-start-button-belongs-to-player-select.md)). The table's own documentation described a saved ball waiting
for a press until 2026-09-05, because that is what the engine did until that afternoon; both were
changed ([0215](../../raw/rules/0215-the-start-button-belongs-to-player-select.md)). Pages: [the start button](../things/start-button.md),
[the Visual Pinball table](../bodies/vpx.md).
