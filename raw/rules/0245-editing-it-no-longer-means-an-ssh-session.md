**Editing it no longer means an ssh session.** The cabinet serves a page that edits this file as
text, shows what the engine made of it — including a value it will clamp — and restarts. Where it is
and what is on it is [operations.md §3a](../../../FlipperEngine/docs/operations.md#3a-the-cabinet-answers-a-browser); the
address is on the glass, in the service menu's `NETWORK` page.
