# Rule 0274 — A path naming a file that is not on disk stops the cabinet

**At the glass: `E 101` means the sound set names a file that is not there** — half a copy, or a
rename ([0274](../../raw/rules/0274-a-path-naming-a-missing-file-stops-the-cabinet.md)). No entry at all is fine; an entry pointing at nothing is not, and one missing
variant out of twelve stops the machine as surely as a missing single ([0274](../../raw/rules/0274-a-path-naming-a-missing-file-stops-the-cabinet.md)). Pages:
[sound sets](../concepts/sound-sets.md).
