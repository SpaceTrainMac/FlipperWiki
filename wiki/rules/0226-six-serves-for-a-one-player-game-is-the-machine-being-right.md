# Rule 0226 — Six serves for a one-player game is the machine being right

**At the glass: count serves against turns before calling anything wrong.** A ball that lives two
seconds always drains inside the fifteen-second window, so every turn costs two serves and a
three-turn game costs six ([0226](../../raw/rules/0226-six-serves-for-a-one-player-game-is-the-machine-being-right.md)). Pages: [the Visual Pinball table](../bodies/vpx.md),
[drain protection](../concepts/drain-protection.md).
