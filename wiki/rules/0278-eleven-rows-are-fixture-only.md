# Rule 0278 — Eleven rows are fixture only

**At the glass: on a cabinet running `rool`, eleven of the forty events make no sound** ([0278](../../raw/rules/0278-eleven-rows-are-fixture-only.md)).
They were added on 2026-09-04 and that set will not have them until a person chooses a file for
each, because a synthesised one would make the hand-picked set a generated one ([0278](../../raw/rules/0278-eleven-rows-are-fixture-only.md)). Pages:
[what the machine says](../concepts/the-sounds.md).
