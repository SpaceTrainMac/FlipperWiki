# The radio

**[The cabinet](../bodies/cabinet.md) plays a radio station when it has been left alone long
enough** ([0260](../../raw/rules/0260-the-cabinet-plays-a-radio-station-when-left-alone.md)). It is a state of the machine like any other and not a screensaver: a slower
version of the same light show, the station's name across
[the four score displays](../things/player-displays.md), and `RADIO` on
[`MATCH`](../things/match-display.md) — or **`NO NET` while it is failing to connect** ([0260](../../raw/rules/0260-the-cabinet-plays-a-radio-station-when-left-alone.md)).
