# Rule 0288 — `MAIN_BONUS_NEXT_STEP`

**At the glass: the count moved** ([0288](../../raw/rules/0288-cue-main-bonus-next-step.md)). It speaks once per advance rather than once per step,
so [completing the bank](../concepts/advance-bonus-bank.md) and [an inlane](../things/inlanes-5000.md)
worth five bonuses both raise it once — and hitting a target does not raise it at all ([0288](../../raw/rules/0288-cue-main-bonus-next-step.md)). Pages: [what the machine says](../concepts/the-sounds.md), [the bonus count](../concepts/the-bonus-count.md).
