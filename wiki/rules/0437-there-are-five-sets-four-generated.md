# Rule 0437 — There are five sets, and four of them are generated

**At the glass: whichever voice the machine is wearing, the list of things it can say is the same**
([0437](../../raw/rules/0437-there-are-five-sets-four-generated.md)). Four of the five sets are generated rather than collected, and all five map
the same cues to the same events ([0437](../../raw/rules/0437-there-are-five-sets-four-generated.md)). **The fifth one sings**: its lyrics go through a
voicebank somebody has to fetch by hand, which makes it the one set a fresh clone cannot build
unattended ([0437](../../raw/rules/0437-there-are-five-sets-four-generated.md)). It supersedes
[0277](../../raw/rules/0277-there-are-four-sets-three-generated.md), which counted four.
