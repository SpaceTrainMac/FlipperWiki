# Rule 0188 — Advertised feature set

**At the glass: everything the flyer sold in 1987 is still there to be played**, and the list is
the closest thing this machine has to a manual written by the people who built it ([0188](../../raw/rules/0188-advertised-feature-set.md)). Two of
the eleven lines exist only in Spanish, and one of those two — *Combinación bancada de luces* — is
the three-stage bank, which the English half of the flyer never mentions at all ([0188](../../raw/rules/0188-advertised-feature-set.md)). Pages:
[the 1987 machine](../bodies/1987.md).
