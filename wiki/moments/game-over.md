# Game over

**`GAME OVER` names the end of a *game*, and it is lit when the last round ends** ([0370](../../raw/rules/0370-game-over-names-the-end-of-a-game.md)). Only
the state that runs the whole game decides that; every state after it inherits the fact rather than
establishing it ([0370](../../raw/rules/0370-game-over-names-the-end-of-a-game.md)).
