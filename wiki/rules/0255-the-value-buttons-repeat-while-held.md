# Rule 0255 — The value buttons repeat while held

**At the glass: start moves to the next entry, the right flipper raises the value and the left
lowers it, and both repeat if you hold them** ([0255](../../raw/rules/0255-the-value-buttons-repeat-while-held.md)). The top two score displays name the entry,
the bottom two show its value, and `MATCH` says `SETUP` ([0255](../../raw/rules/0255-the-value-buttons-repeat-while-held.md)). Pages:
[the service menu](../moments/the-service-menu.md), [the MATCH display](../things/match-display.md).
