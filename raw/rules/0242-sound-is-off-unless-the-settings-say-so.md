- **Sound is off unless the settings say `"sound": true`.** The cue that fired is always *shown* —
  the music and, since 2026-09-08, the effects: the engine's game code raises all forty of them,
  which [sound.md](../../../FlipperEngine/docs/sound.md) catalogues in its §4, so a silent effects
  panel during a game is an engine older than that day and not the instrument.
