# Rule 0275 — A cabinet with no amplifier is `"sound": false`

**At the glass: a machine set to make no noise cannot be stopped by a sound set** — it never looks
for a folder and never reads a map, so `E 101` and `NONE SET` are both impossible ([0275](../../raw/rules/0275-a-cabinet-with-no-amplifier-is-sound-false.md)). Pages:
[sound sets](../concepts/sound-sets.md).
